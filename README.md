🌱 Soil Moisture Monitoring System
Система для мониторинга влажности почвы на основе спутниковых данных SMAP (NASA) с веб-интерфейсом. Позволяет выбирать область на карте, задавать временной интервал и получать оценку среднего содержания влаги в поверхностном слое почвы (0–5 см) в процентах.

Проект построен на микросервисной архитектуре с использованием Docker, включает в себя:

1. Flask – фронтенд и пользовательские запросы.

2. FastAPI – асинхронный бэкенд для взаимодействия с Google Earth Engine и базой данных.

3. PostGIS – пространственная база данных для хранения запросов и результатов.

4. Nginx – reverse proxy для маршрутизации запросов.

5. Google Earth Engine API – доступ к спутниковым данным SMAP.

🏗 Архитектура
1. Nginx обслуживает статические файлы и перенаправляет API-запросы к соответствующим сервисам.

2. Flask рендерит HTML-страницы и принимает пользовательские запросы на анализ, сохраняет их в БД и отправляет задачу в FastAPI.

3. FastAPI выполняет фоновую задачу: запрашивает данные SMAP через Earth Engine, обрабатывает и сохраняет результаты в БД.

4. PostGIS хранит геометрию полигонов, метаданные запросов и полученные значения влажности.

⚙️ Предварительные требования 

Установленные Docker и Docker Compose (обычно входят в состав Docker Desktop).

Учётная запись Google Cloud с включённым Earth Engine API и созданным сервисным аккаунтом (см. инструкцию ниже).

Файл ключа сервисного аккаунта в формате JSON.

🔧 Установка и запуск

Клонирование репозитория
    
    git clone https://github.com/yourusername/soil-moisture-monitoring.git
    
    cd soil-moisture-monitoring

Настройка ключа Google Earth Engine:

Перейдите в Google Cloud Console.

Создайте проект (или выберите существующий).

Включите Earth Engine API для этого проекта.

Создайте сервисный аккаунт и скачайте JSON-ключ.

Поместите файл ключа в папку secrets/gee_service_account.json относительно корня проекта.

    mkdir -p secrets
    # переместите скачанный ключ в secrets/gee_service_account.json

Запуск с Docker Compose

Соберите и запустите контейнеры:

    docker-compose up --build

После успешного запуска откройте браузер и перейдите по адресу: http://localhost:8080.

🖥 Использование

На карте по умолчанию отображается прямоугольник (область анализа). Вы можете перемещать карту и нажать «Нарисовать область», чтобы обновить прямоугольник по текущим границам карты.

Введите название анализа (опционально).

Выберите даты начала и окончания (рекомендуется период не более 30 дней, данные SMAP доступны с 2015 года).

Нажмите «Запустить анализ».

Наблюдайте за статусом выполнения. После завершения отобразится средняя влажность почвы за период.

Для просмотра детализации по дням откройте консоль браузера (F12) – там будут выведены значения по каждой дате.
